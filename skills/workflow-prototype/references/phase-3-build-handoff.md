# Phase 3 — Build · Run · Handoff

**Skills used:** [core-prototype](../../core-prototype/SKILL.md), [dev-fe-developer](../../dev-fe-developer/SKILL.md), [dev-be-developer](../../dev-be-developer/SKILL.md)

Prerequisite: interface confirmed ([Phase 1](phase-1-research-interface.md)) and, if there's a UI, the mockup approved ([Phase 2](phase-2-ui-design-gate.md)).

## Build
Follow [core-prototype](../../core-prototype/SKILL.md) for speed-first building:
- Single file if possible.
- Use the stack from Phase 1.
- Implement the confirmed interface (and the approved UI, via [dev-fe-developer](../../dev-fe-developer/SKILL.md); stub the backend via [dev-be-developer](../../dev-be-developer/SKILL.md)).
- Hardcode anything that isn't the core concern.

## Run
Run it and show **real output** — not a description of what it would do.

## Handoff notes
- What's hardcoded / stubbed.
- What would need to change for production.
- Estimated effort to productionize (S / M / L / XL).

For turning the prototype into a tracked feature, hand off to [workflow-feature](../../workflow-feature/SKILL.md).
